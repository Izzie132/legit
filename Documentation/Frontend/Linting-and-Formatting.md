# Linting and Formatting

## ESLint

This project uses [ESLint]() to handle linting. The configuration used for ESLint can be found in the [.eslintrc.cjs](../../Web/client-app/.eslintrc.cjs)
file.

## Prettier

This project uses [Prettier]() to handle formatting the frontend code. The configuration for Prettier can be found in the
[.prettierrc](../../Web/client-app/.prettierrc) file. This configuration will be used globally within the project, run
from within the [Husky](../Tooling/Husky.NET.md) pre-commit hooks.
